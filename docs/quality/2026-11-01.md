# Quality check against the 10 rules (2026-11-01)

The file name matches the other repositories' quality pass; this repository was built later
(2026-11-09 and 2026-11-10) with the rules applied from the start. Run on Windows 11 (Intel Core
i7-13700H) with Python 3.14.5 in the repo's `.venv`. Atheris runs only in CI (Linux wheels).
Mutations were applied one at a time by a scratch script that restores each file in a `finally`
block right after its test run (`pytest -q -x --timeout=120`).

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | pass | No network calls. File reads are size-checked before reading (seeds 64 KiB, dictionaries 256 KiB, replay inputs 64 KiB); non-ASCII dictionaries raise `DictionaryError`; the CLI turns `CorpusError`, `DictionaryError`, `ValueError` and `OSError` into one line and exit 2 (tested). The tracer returns every exception of the target as data (`Hang` included) and re-raises `KeyboardInterrupt` and `SystemExit`; the Atheris callback lets every exception except `ParseError` through as a crash. No swallowed exceptions in `src/`. |
| 2 | Writes safe to retry | pass | Corpus and crash files are named by the SHA-1 of their content and written by temp file, `fsync` and `os.replace`; saving twice is a no-op, and a failed write removes its temp file (tested). `stats.json` and the bench JSON use the same atomic write. |
| 3 | No race conditions | N/A | Single-threaded engine and CLI; each run writes only to its own `--out` folder. libFuzzer's own processes are Atheris's concern, run in CI. |
| 4 | Don't trust the clock | pass | Durations and the `--seconds` deadline use `time.monotonic`; no wall-clock time is stored. Hang detection counts traced lines (a step budget), not time, so it is deterministic. |
| 5 | Read before changing | pass | No environment variables are read (stated in the README); every doc link is checked by `audit_repo.py`. |
| 6 | Never break compatibility | pass | Seeds and dictionaries use the standard libFuzzer/AFL formats, so the same files work with Atheris; crash files use libFuzzer-style SHA-1 names. |
| 7 | One source of truth | pass | One `fuzz_one` per target serves both engines; the target list lives in `targets/__init__.py` and the CLI, bench and Atheris harness read it. Limits are module constants next to the code that enforces them. Python >=3.11 in `pyproject.toml`, CI 3.12, README. |
| 8 | Small changes, no secrets, validate input | pass | Secret grep: nothing (fixture URLs use `example.invalid`). Every CLI number is validated by an argparse type (exit 2, tested); `FuzzConfig` rejects impossible budgets; dictionaries reject bad escapes, empty or 129-byte tokens and over 1,000 tokens; each parser has a size limit and a nesting limit so deep input is a `ParseError`, not a `RecursionError` (tested). |
| 9 | Tests that can actually fail | fixed | The suite covers empty, invalid and failure paths (empty input to every mutator, bad files, impossible budgets, a broken oracle). 9 of 10 mutants were killed and 1 is equivalent; one mutant survived the first run and a test now kills it (table below). |
| 10 | Re-verify | pass | Results below; `.tmp/check.sh` re-runs lint, types, tests, audit and `audit_repo.py`. |
